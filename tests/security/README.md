# Mandatory security scenarios

1. Owner A cannot access Owner B customer.
2. Owner A cannot access Owner B invoice.
3. Staff cannot delete customer.
4. Staff cannot delete product.
5. Staff cannot cancel finalized invoice.
6. Staff cannot access subscription APIs.
7. Staff cannot access admin APIs.
8. Duplicate Razorpay webhook is idempotent.
9. Concurrent invoice generation never duplicates invoice number.
10. Offline invoice sync never duplicates invoices.
